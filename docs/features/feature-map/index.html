利用条件から探す

種類説明条件
エディター本体の操作ブロック編集 · スプライト基本操作。配置によって入口・利用できる操作が異なります。
対応拡張のある機能フォーム・YAML · テスト対応する拡張の追加と、その拡張のデータやテストハットが必要です。
組み込みGuideエディター案内ガイド付き作品が呼び出したときだけ表示。同じ文書内で登録・表示された対象に限ります。
ブラウザーと保存先プロジェクト一覧 · 作品フォルダファイル操作はブラウザーAPI、保存先、アクセス権に依存します。
GitHub接続GitHubで開発接続先を設定した対応ホストと、アカウント認証が必要です。
明示的に有効化する機能Gitの版に戻すtwPlusGitRestoreVersion=1 が必要で既定は無効。通常の復元ポイントとは別です。
アドオンアドオン設定個別に設定します。下の既定値は、利用中のブラウザーの現在値ではありません。
API・Desktop専用の接続AIエージェント設定 · CIWeb版のAIメニューは設定済みHTTPSサービスを開きます。OSでの起動にはDesktop側の対応が必要です。JUnitはAPIでありEditorのダウンロードボタンではありません。
